## **经典题型**

### Two-pointer:
>个人感觉two pointer常用于处理在array/LinkedList等连续数据结构中，可以把问题的解决往one-pass O(n)靠

- Increasing Triplet Sequences (Leetcode 334)
  >Given an integer array nums, return true if there exists a triple of indices (i, j, k) such that i < j < k and nums\[i] < nums\[j] < nums\[k]. If no such indices exists, return false.  
  >特殊在巧妙的把问题转化成分段问题

  ```java
  class Solution {
  
    public boolean increasingTriplet(int[] nums) {
      if (nums.length < 3) {
        return false;
      }
      // two-pointer
      int min = nums[0];
      // make sure else if can find second min value in nums
      int secondMin = Integer.MAX_VALUE;
      for (int i = 1; i < nums.length; i++) {
        if (nums[i] <= min) {
          min = nums[i];
        } else if (nums[i] <= secondMin) {
          secondMin = nums[i];
        } else {
          return true;
        }
      }
      return false;
    }
  }
  ```

- Squares of a Sorted Array (Leetcode 977):
  >Given an integer array nums sorted in non-decreasing order, return an array of the squares of each number sorted in non-decreasing order.  
  >特殊在于这个two pointer是从两边逼近中间  

  ```java
  public class Leetcode977 {
    public int[] sortedSquares(int[] nums) {
      int start = 0;
      int end = nums.length - 1;
      int[] ret = new int[nums.length];
      // two pointer
      for (int i = nums.length - 1; i >= 0; i--) {
        if (Math.abs(nums[start]) > Math.abs(nums[end])) {
          ret[i] = nums[start] * nums[start];
          start++;
        } else {
          ret[i] = nums[end] * nums[end];
          end--;
        }
      }
      return ret;
    }
  }
  ```



### DFS：
>DFS普遍采用iteration，能用于很多场景，比如Tree/Array等的遍历上，通常如果需要得到全部解/树类问题需要走到深处，会优先考虑DFS

- Palindrome Partitioning(Leetcode 131)
  >Given a string s, partition s such that every substring of the partition is a palindrome. Return all possible palindrome partitioning of s. A palindrome string is a string that reads the same backward as forward.  
  >典型dfs，if退出条件+dfs部分，多了个index来调节位置/temp存当前解  

  ```java
  class Solution {
    public List<List<String>> partition(String s) {
      List<List<String>> ret = new ArrayList<>();
      dfs(s, ret, new ArrayList<>(), 0);
      return ret;
    }

    private void dfs(String s, List<List<String>> ans, List<String> temp, int index) {
      if (index == s.length()) {
        ans.add(new ArrayList<>(temp));
      } else {
        for (int i = index; i < s.length(); i++) {
          String sub = s.substring(index, i + 1);
          if (!isPalindrome(sub)) {
            continue;
          }
          temp.add(sub);
          dfs(s, ans, temp, i + 1);
          temp.remove(temp.size() - 1);
        }
      }
    }

    private boolean isPalindrome(String s) {
      char[] arr = s.toCharArray();
      for (int i = 0; i < arr.length / 2; i++) {
        if (arr[i] != arr[arr.length - i - 1]) {
          return false;
        }
      }
      return true;
    }
  }
  ```
